# Processed data

This directory is for reviewed, normalized, redacted, deduplicated, and schema-conformant dataset exports derived from raw data.

Processed records must follow [the dataset specification](../../docs/dataset.md), use UTF-8, and carry their language, script, label, category, red flags, source type, and split metadata. Keep train, validation, and test exports separate. Test data must remain isolated during development.

The real Sotorko processed dataset is not included yet.
