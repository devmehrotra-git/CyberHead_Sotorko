# Raw data

This directory is for source material collected before normalization or annotation. Raw files should preserve their original content and provenance as safely as possible, including source references, collection dates, and consent or usage metadata where applicable.

Do not place secrets, live credentials, OTPs, payment details, or unredacted personal information here. Do not treat raw data as train, validation, or test data until it has passed quality review, redaction, deduplication, annotation, and split assignment.

The real Sotorko dataset is not included yet.
